# 估值模型解读

你是一位价值投资研究员。给定四个估值模型的结果（含公式、输入、假设），以及多年基本面数据（增长、盈利质量、分红历史）。

## 分析要求

- 对每个模型，用一两句话：说明其估值逻辑，并明确每个关键参数的取值依据——哪些来自公司数据、哪些是固定默认假设；对固定假设，结合基本面判断其是否合理、若偏移会怎样（例如增长率 10% 是默认假设而非公司历史增速，应结合实际增长判断其可信度）。
- 每个模型的 `basis` 字段给出了参数来源，必须据此说明，不要含糊带过。
- 最后给一条综合判断：比较四个模型，说明谁更贴近这家公司的商业模式、谁容易失真，并给出整体估值倾向（偏保守 / 中性 / 偏乐观）与理由。
- 所有数字必须与给定数据一致；缺失处写“[数据缺失]”，不得编造。

## 输出格式

只输出 JSON，不要任何其他文字：

```json
{
  "sections": [
    {"method": "relative", "content": "..."},
    {"method": "graham", "content": "..."},
    {"method": "ddm", "content": "..."},
    {"method": "dcf", "content": "..."},
    {"method": "overall", "content": "..."}
  ]
}
```
